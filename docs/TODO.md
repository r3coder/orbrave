# 구현 리스트

(v0.5.3, 2026-11-07 기준으로 정리)

## 1. 오브 슬롯

필드 아래에 오브를 던져 넣는 슬롯 4개: **약하게** · **세게** · **🎲 변주** · **🎛 편집(전문가용)**.
처음 계획의 "MIDI 편집" 슬롯은 따로 두지 않고, 변주 슬롯의 **✎ 악보**(피아노 롤)로 들어갔다.

- [x] 기존 MIDI 편집 영역 제거, 슬롯 줄 배치 (`#slotQuieter`, `#slotLouder`, `#slotVary`, `#slotEdit`)
- [x] 약하게 / 세게: 한 번에 × 0.8 / × 1.2, 각 방향 3단계까지 (`.postgain`) — 프리셋·공유 코드(`vg`)·서버 업로드(`gains`, 5–400%)에 저장
- [x] 변주: 오브마다 변주 16개까지, ◀ ▶로 고르기, ✎ 악보로 음 고치기, 🎹 풀 스케일 (v0.5.0)
- [x] 🎛 편집: 어택 · 디케이 · 필터 · EQ · 이펙트를 바꿔 커스텀 오브 만들기, 서버 업로드 (v0.5.0)
- [x] 처리된 오브는 다시 잡아서 재생 버튼·보관함·필드·다른 슬롯으로 보낼 수 있음 (효과 누적)
- [x] 다른 영역에 던질 때와 같은 던지기 판정·애니메이션
- [x] 문구 ko / en / ja
- [x] 모바일: 슬롯 줄이 항상 나와 있음 (`src/orbsMobile.css`). 스템은 넓은 화면 전용
- [x] 모바일 위쪽 줄: 전부 비우기 · 미리듣기/터치 중인 오브 설명 · ⇪ 내보내기. 빈 화면을 위로 스와이프하면 오브가 느리게, 아래로 스와이프하면 빠르게 떨어짐
- [x] 던지기 판정: 마우스를 멈췄다가 놓으면 던지기가 아니라 내려놓기 (멈춘 동안 pointermove가 없어 예전 위치로 속도를 재던 문제 수정)
- [ ] **실제 마우스로 던지기 확인** (지금까지 테스트는 합성 포인터 이벤트로만 함) — 빠르게 끌다가 멈추고 놓기, 위로 튕기기(슬롯 → 필드), 곡에서 꺼내 오른쪽으로 던지기
- [ ] **음량 변화 실제 소리 확인** — 약하게 / 세게 3단계씩, 솔로 중일 때, 편집 칸의 게인과 겹칠 때
- 모바일 레이아웃 확인: `npm run dev` 후 `/tools/mobile-preview.html` (여러 기기 크기를 한 화면에)
- 참고: 콤보 오브는 슬롯에 못 넣음

## 2. 튜토리얼

계획했던 "순서대로 따라 하는 10단계 투어" 대신, **도구가 하나씩 풀리는 방식**으로 구현됨.
사용자 동작(던진 수 · 움직인 수 · 저장/공유 · 재생 시간)이나 시간이 지나면 다음 단계가 열리고,
해당 UI만 밝게 두고 나머지를 몇 초 어둡게 하며 안내 한 줄을 띄운다 (`src/tutorial.js` spotlight).
단계 정의와 조건은 `src/orbs/guide.js` 맨 위 (`TUT`) 주석에 있음.

- [x] 단계 관리 틀 — UI 강조, 동작 감지 후 다음 단계, 한 번에 안내 하나씩 (대기열)
- [x] 진행 상태 localStorage에 기억 (`orbTutorial`, 새로고침해도 이어서)
- [x] 다시 보기 — ↺ 튜토리얼 재실행 버튼 (진행과 현재 세트를 지우고 새로고침)
- [x] 문구 ko / en / ja (`src/orbsI18n.js`, `tut*`)
- [x] 첫 오브: 던지기 힌트 + 반투명 오브 애니메이션 → 볼륨 노브 데모 + 팁 (`orbFirstOrb`)
- [x] 콤보 오브 소개 — 콤보 하나를 일부러 떨어뜨려 필드에서 멈추고 설명 (그 전에 콤보에 마우스를 올려도 설명)
- [x] 1 보관함 → 2 약하게/세게 슬롯 → 3 변주 슬롯(✎ 악보) → 4 프리셋 저장 배너 → 5 WAV/공유 → 6 Strudel 코드 링크 (+ 스템 열기, 🎛 편집이 조용히 나옴) → 7 스템 열기 안내 → 8 스템 모드 설명과 루프 모드로 돌아가기
- [ ] 건너뛰기 버튼 — 지금은 안내가 몇 초 뒤 저절로 사라지고 아무 곳이나 누르면 닫히지만, "도구 전부 바로 꺼내기"(`tutUpTo(TUT_LAST)`)를 사용자가 고를 수는 없음. 필요한지 결정
- [ ] 볼륨 노브 단계: 데모만 보여주고 사용자가 직접 돌리길 기다리지는 않음. 이대로 둘지 결정
- [ ] 처음 방문하는 사람으로 처음부터 끝까지 한 번 통과해 보기 (넓은 화면 / 폰 각각)

## 3. 코드 정리

- [x] `src/orbs.js`(약 5,600줄)를 기능별 파일 15개로 나눔 (`src/orbs/*.js` + 진입점 `src/orbs.js`, v0.5.2)
  - 파일들은 사슬처럼 로드됨: 각 파일이 바로 앞 파일을 **첫 번째 import**로 가져와서, 원래 한 파일일 때와 같은 순서로 실행됨. 새 import를 추가할 때 이 첫 줄 순서를 바꾸지 말 것
  - 여러 파일이 값을 바꾸는 변수는 `state.js`의 `S` 객체에 있음 (`S.playing`, `S.song` …). ES 모듈은 다른 파일에서 `let`을 다시 대입할 수 없기 때문
- [ ] 가장 큰 파일 (`stems.js` 약 900줄, `presets.js`·`slots.js` 약 550줄) 더 나눌지 결정
