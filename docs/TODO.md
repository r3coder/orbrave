# 구현 리스트

## 1. 오브 슬롯 (MIDI 편집 / 음량 감소 / 음량 증가 / 변주)

기존 MIDI 편집(롤) 영역을 없애고, 화면 아래에 오브를 던져 넣는 슬롯 4개를 둔다.

- [x] 기존 MIDI 편집 영역 제거
- [x] 아래쪽에 슬롯 4개 배치: **MIDI 편집** · **음량 감소 (80%)** · **음량 증가 (120%)** · **변주**
- [x] 오브를 슬롯에 넣으면 해당 탭이 아래에서 올라오며 기존 MIDI 편집창처럼 열림
  - MIDI 편집: 기존 편집 기능 그대로 (높이 2/3 탭)
  - 음량 감소 / 증가: 오브 음량 × 0.8 / × 1.2 — 작은 탭(약 150px)에 "100% → 80%", 다시 적용·되돌리기 버튼
  - 변주: 그 악기만 새 시드 — 작은 탭에 `#이전 → #새`, 다시 굴리기·되돌리기
- [x] 처리된 오브는 다시 잡아서 재생 버튼·보관함·필드·다른 슬롯으로 보낼 수 있음 (효과 누적됨)
- [x] 다른 영역에 던질 때와 같은 던지기 판정·애니메이션 사용
- [x] 문구 ko / en / ja
- [x] 오브별 음량 추가 (`.postgain`) — 프리셋·공유 코드(`vg`)·서버 업로드(`gains`, 5–400%)에 저장
- [x] 모바일에도 슬롯 표시 — 단, 편집(피아노 롤)은 넓은 화면 전용: 모바일에선 편집 슬롯·탭·튜토리얼 단계 없음 (약하게 / 세게 / 변주 / 복제 4개만)
- 모바일 레이아웃 확인: `npm run dev` 후 `/tools/mobile-preview.html` (여러 기기 크기를 한 화면에)
- [ ] 실제 마우스로 던지기 확인 (테스트는 합성 포인터 이벤트로만 함)
- [ ] 음량 변화 실제 소리 확인
- 참고: 콤보 오브는 슬롯에 못 넣음 · 슬롯은 오브 5개를 넣은 뒤 나타남 (`revealRoll()`로 먼저 표시 가능)
- 튜토리얼용 id: `#slots`, `#slotMidi`, `#slotQuieter`, `#slotLouder`, `#slotVary`, 탭 `#roll[data-mode]`

## 2. 튜토리얼 정비

현재 첫 방문 안내(`src/orbs.js` "first visit" — 던지기 힌트 + 볼륨 다이얼 팁)를 단계형 튜토리얼로 확장한다.
단계마다 해당 UI를 강조하고, 사용자가 실제로 해당 동작을 하면 다음 단계로 넘어간다.

### 현재 구현 상태

- 구현됨 (첫 방문 1회, localStorage `orbFirstOrb`):
  - 오브 추가: 화면 중앙 힌트 + 반투명 오브가 2.6초마다 필드→플레이어로 날아가는 애니메이션. 첫 오브가 들어가면 종료
  - 음량 조절: 첫 오브가 소리 나면 5초간 음량이 내려갔다 올라오는 데모 + "노브를 돌려서 음량을 조절하세요" 팁 (자동으로 사라짐, 사용자가 돌리길 기다리지는 않음)
- 미구현: 단계 관리 틀(강조·진행 저장·건너뛰기·다시 보기), 3단계 이후 전부

### 단계

- [ ] 단계 관리 틀 — UI 강조, 동작 감지 후 다음 단계, 진행 저장
- [ ] 2단계를 데모 방식 → 사용자가 노브를 직접 돌릴 때까지 기다리는 방식으로 바꿀지 결정

1. [x] **오브 추가** — 필드의 오브를 재생 버튼으로 던지기 (첫 방문 힌트로 구현됨, 단계 틀에 편입 필요)
2. [x] **음량 조절** — 볼륨 다이얼 돌리기 (데모 + 팁으로 구현됨, 단계 틀에 편입 필요)
3. [ ] **콤보 오브 소개** — 콤보 오브 하나를 필드에 생성하고 약 5초간 강조 표시하며
       "여러 개의 오브가 합쳐진 오브입니다" 안내 (사용자 동작 없이 시간 지나면 다음 단계)
4. [ ] **오브 슬롯** — 오브를 아래 슬롯(MIDI 편집 / 음량 감소 / 음량 증가 / 변주)에 던져 넣기 (1번 기능 구현 후)
5. [ ] **보관함 저장** — 오브를 보관함으로 보내기
6. [ ] **프리셋 저장** — 프리셋 저장 과정 안내
7. [ ] **공유 기능 안내** — 공유 코드 복사 / 서버 공유 위치 알려주기 (실행은 안 시킴)
8. [ ] 프리셋 저장 후 → **MIDI 편집** 안내
9. [ ] **스템 생성** — 전체 곡 스템 만들기를 보여주기만 함
10. [ ] **스템 닫기** → 튜토리얼 종료

- [ ] 진행 상태 localStorage에 기억 (한 번만 표시, 중간에 끄면 이어서 또는 건너뛰기)
- [ ] 건너뛰기 / 다시 보기 버튼
- [ ] 문구 ko / en / ja (`src/orbsI18n.js`)
- [ ] 8단계(MIDI 편집)는 슬롯 방식으로 바뀐 편집창 기준으로 안내
